# موقع الإسعافات الأولية (Streamlit)

هذا المشروع تحويل للنوتة `first_aid_rag_v2.ipynb` إلى موقع Streamlit شغّال.

## هيكل الملفات

```
first_aid_streamlit/
├── app.py                    ← الموقع نفسه (Streamlit)
├── build_index.py            ← سكريبت يشتغل مرة واحدة بس، محليًا، لتجهيز الفهرس من الـ PDF
├── rag_core.py                ← الكود المشترك بين الاثنين (بحث، تصنيف، إلخ)
├── requirements.txt           ← مكتبات تشغيل الموقع (خفيفة)
├── requirements-build.txt     ← مكتبات إضافية تحتاجها فقط عشان تشغّل build_index.py
├── data/                      ← (فاضي دلوقتي) هتتولد فيه ملفات الفهرس بعد build_index.py
└── pdf_images/                ← (فاضي دلوقتي) هتتولد فيه صور صفحات الـ PDF
```

## الخطوة 1: تجهيز الفهرس محليًا (مرة واحدة بس)

الموقع نفسه **لا يعالج ملف الـ PDF مباشرة** — لازم تجهّز الفهرس مرة واحدة على جهازك
الأول، لأن معالجة الـ PDF (بمكتبة docling) عملية ثقيلة ومش مناسبة تتكرر كل مرة حد
يفتح الموقع.

1. ثبّت بايثون 3.11 على جهازك (فيه شرح للنسخة تحت).
2. جهّز بيئة افتراضية وثبّت المتطلبات:
   ```bash
   python -m venv venv
   source venv/bin/activate        # على ويندوز: venv\Scripts\activate
   pip install -r requirements-build.txt
   ```
3. شغّل السكريبت وحدد مكان ملف الـ PDF عندك:
   ```bash
   python build_index.py --pdf "First aid reference guide_V4.1_Public.pdf"
   ```
4. لما يخلص، هتلاقي:
   - مجلد `data/` فيه 5 ملفات (`chunks_df.pkl`, `tfidf_index.pkl`, `bm25_index.pkl`,
     `embedding_matrix.npy`, `page_to_images.pkl`)
   - مجلد `pdf_images/` فيه صور كل صفحة استُخرجت منها صورة.

هذين المجلدين (`data/` و `pdf_images/`) هما اللي لازم يترفعوا مع باقي الموقع —
مش ملف الـ PDF نفسه.

## الخطوة 2: تجربة الموقع محليًا

```bash
pip install -r requirements.txt
streamlit run app.py
```

هيفتح على `http://localhost:8501`.

## الخطوة 3: رفع الملفات فين؟ (النشر Deploy)

أسهل طريقة مجانية هي **Streamlit Community Cloud**:

1. اعمل مستودع (repo) على GitHub وارفع عليه كل محتويات هذا المجلد كاملة،
   شامل مجلد `data/` ومجلد `pdf_images/` (وليس ملف الـ PDF الأصلي — مش محتاجينه بعد
   تجهيز الفهرس).
   - لو مجلد `pdf_images/` كبير جدًا (فيه مئات الصور)، ممكن ترفعه، بس خُد بالك إن
     GitHub بيحدد حجم الملف الواحد بـ 100MB والمستودع بشكل عام يفضل يكون معقول
     الحجم. لو كبير أوي، فكّر تستخدم Git LFS أو تستضيف الصور مكان تاني.
2. روح على https://share.streamlit.io وسجّل دخول بحساب GitHub.
3. اختر "New app" وحدد المستودع، والملف الرئيسي `app.py`.
4. من "Advanced settings" اختار **Python 3.11** (راجع الجزء الجاي).
5. اضغط Deploy.

## نسخة بايثون المطلوبة

النوتة الأصلية اشتغلت على بايثون **3.12.10**. بس للنشر على Streamlit Cloud بننصح
بـ **Python 3.11** لأنها الأكثر استقرارًا مع مكتبات زي `sentence-transformers` و
`scikit-learn` وقت كتابة هذا الملف. لو حصل تعارض في المتطلبات، جرّب 3.12.
أي نسخة من 3.10 لـ 3.12 هتشتغل مع `app.py` و `requirements.txt` بتاعته.

## ملاحظة مهمة جدًا: النموذج اللغوي (LLM)

الكود بيدعم نوعين من مزوّدي الذكاء الاصطناعي، ويختار تلقائيًا حسب المتغيرات
البيئية اللي هتحطها — مفيش تعديل على الكود مطلوب:

### الخيار المفضّل للنشر أونلاين: Groq (سحابي، مجاني حاليًا وسريع)

1. اعمل حساب واحصل على مفتاح API من: https://console.groq.com/keys
2. حدد المتغيرات دي (بدل الـ Ollama القديمة):
   ```bash
   export GROQ_API_KEY="gsk_xxxxxxxxxxxxxxxxxxxx"
   export LLM_MODEL_NAME="llama-3.3-70b-versatile"
   ```
   (تقدر تستبدل الموديل بأي موديل تاني متاح عندك في Groq، زي
   `llama-3.1-8b-instant` لو عايز أسرع وأرخص، أو تتأكد من أحدث الموديلات
   المتاحة من داشبورد Groq نفسه لأنها بتتغيّر بمرور الوقت).
3. **مهم**: طالما `GROQ_API_KEY` موجود، الكود هيستخدم Groq تلقائيًا
   ومش هيحاول يوصل لـ Ollama خالص. مفيش حاجة تانية تتغيّر.

على **Streamlit Community Cloud** تحدد المتغيرات دي من إعدادات التطبيق
تحت "Secrets" بصيغة TOML، مثلًا:
```toml
GROQ_API_KEY = "gsk_xxxxxxxxxxxxxxxxxxxx"
LLM_MODEL_NAME = "llama-3.3-70b-versatile"
```
(Streamlit بيحوّل الـ secrets دي لمتغيرات بيئة تلقائيًا، فالكود هيلاقيها
عادي عن طريق `os.environ`).

### الخيار التاني: Ollama محلي (لو شغّلت الموقع على جهازك بس)

لو عايز تجرب على جهازك بدون نت أو بدون مفتاح Groq، سيب `GROQ_API_KEY` فاضي
وشغّل Ollama محليًا، والكود هيستخدمه تلقائيًا:
```bash
export OLLAMA_URL="http://localhost:11434/api/generate"
export LLM_MODEL_NAME="llama3.2"
```
لكن ده مش هيشتغل لو نشرت الموقع أونلاين، لأن سيرفر Streamlit Cloud مش
هيقدر يوصل لجهازك الشخصي.

### لو مفيش أي مفتاح ولا Ollama شغّال؟

الموقع مش هيقع — هيعرض تلقائيًا "أقرب المقاطع من الكتاب" بدل الإجابة
المولّدة بالذكاء الاصطناعي، مع رسالة توضح إن الاتصال بالـ LLM فشل.

## نصيحة بخصوص الموارد

خطة Streamlit Community Cloud المجانية فيها حد أقصى للذاكرة (~1GB). النماذج
المستخدمة هنا (`all-MiniLM-L6-v2` و `cross-encoder/ms-marco-MiniLM-L12-v2`) خفيفة
نسبيًا وبتتحمّل الحد ده غالبًا، لكن لو الموقع طلع بطيء أو وقع، فكّر في:
- خطة مدفوعة بذاكرة أكبر.
- استضافة الموقع على منصة تانية (Render, Railway, أو سيرفر خاص).
